# Package date ownership audit

Reusable parsing, validation, control serialization, civil/local calendar arithmetic belong to the internal `@revolist/dates` package. Working calendars, task/dependency duration calculations and event-range scheduling policy belong to commercial `@revolist/revogrid-pro/dates`. Consumers retain application policy. The package remains private and is bundled into product distributions.

## Intentional differences retained

- Strict timeline instants reject impossible civil dates and zone-less datetimes. Legacy temporal operands and chart detection retain their existing native-parser acceptance and syntax restrictions; consolidation does not silently tighten them.
- Local calendar arithmetic follows DST and wall-clock fields. UTC duration arithmetic follows elapsed time. These are different operations.
- Time-matrix coercion disables Date cloning for its read-only hot path; normal coercion clones by default.
- Native controls default to minute precision; grouped datetime operands explicitly retain seconds.
- Clock capture (`new Date()`), Date branches in deep clones, normalized timestamp comparisons in interval hot paths, and application-specific Intl display options are primitives or feature policy, not duplicated parsing algorithms.
- Microsoft Project wire conversion and spreadsheet format token evaluation retain their specialized encoding and display contracts.

## Regression coverage

Shared and consumer tests cover the local-year serialization defect, early-year Filter AST validation, and weekly recurrence year remapping (owned by Pro scheduling tests). Shared contracts also cover civil month clamping, native local month overflow, DST day shifts, offset restrictions, long weekday ranges, invalid scalar inputs, and clone identity. Browser coverage checks date filters/time matrices, packaged Kanban CRUD, and an early-year datetime control commit.
