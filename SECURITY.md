# Security Policy

This policy covers the open-source Revo UI library (`@revolist/ui`), its bundled internal workspace utilities, and the gallery and documentation maintained in this repository.

## Supported versions

Security fixes target the latest stable release. Older releases receive fixes on a best-effort basis; upgrade to the latest stable version to receive available fixes. Mitigation guidance may be provided when a fix is not immediately available.

## Report a vulnerability privately

Email [info@rv-grid.com](mailto:info@rv-grid.com). If GitHub private vulnerability reporting is enabled for this repository, you may also use **Security → Advisories → Report a vulnerability**.

Do not include suspected vulnerability details in public issues, discussions, or pull requests. Please provide:

- Affected package, component, and version range.
- Potential impact and the conditions needed to exploit the issue.
- Reproduction steps, a minimal sample, or a proof of concept.
- Browser, framework, operating system, and relevant configuration.
- Any known workaround or suggested mitigation.

Remove credentials, personal information, and customer data from reproductions. If you are unsure whether a report is security-related, use the private email channel first. Ordinary bugs can be reported through [GitHub Issues](https://github.com/revolist/revo-ui/issues).

## Response and coordinated disclosure

Reports for the open-source Revo UI project are reviewed on a best-effort basis, without guaranteed response or remediation times. Maintainers will provide updates as the investigation progresses. RevoGrid Pro response commitments, including the two-business-day acknowledgement target, do not apply to this open-source project.

Please coordinate disclosure with maintainers and allow time for a fix to be released before publishing vulnerability details. Security fixes and affected versions are communicated in release notes; a GitHub Security Advisory may also be published. Follow [Revo UI releases](https://github.com/revolist/revo-ui/releases) for updates.

## Responsible research

Make a good-faith effort to avoid privacy violations, data loss, and service disruption. Test with systems and data you own or are authorized to assess, and collect only what is necessary to demonstrate the issue. Let us know whether and how you would like to be credited when the issue is disclosed.

For commercial RevoGrid Pro products, use the separate [RevoGrid Pro security policy](https://github.com/revolist/revogrid-pro/blob/main/SECURITY.md). The broader [Revolist security practices](https://rv-grid.com/pro/policies/security) describe RevoGrid supplier security processes.
